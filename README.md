# MOSS-TTS（SRT/TTS 增强分支）

本仓库基于 `MOSS-TTS`，在原始能力基础上增加了更适合本地工作流的增强功能，重点面向字幕分段配音与本地批量处理场景。

## 当前分支定位

这个分支主要用于：

- 提供更适合本地使用的 WebUI 启动方式
- 提供 `SRT 分段转音频` 工作流
- 增加本地角色库、参数预设、停止当前生成等增强能力
- 保持对上游能力的兼容，同时把本地增强集中在包装层中维护

## 当前增强功能

- SRT 分段转音频
- 本地角色库
- 参数预设
- 停止当前生成
- 已有任务结果加载
- 同任务名断点续跑（跳过已完成片段）
- Premiere XML 导出
- WebUI 启动端口 fallback 优化
- 部分 Gradio 兼容修复

## 快速开始

1. 运行 `init.bat`
2. 等待环境初始化完成
3. 运行 `启动 WebUI.bat`

## 关键入口

- `init.bat`：初始化环境
- `scripts/launch_webui.py`：本地增强入口
- `启动 WebUI.bat`：启动 WebUI

## 说明

- 本仓库不是单纯的上游镜像，而是带有本地工作流增强的分支
- 权重、缓存、输出文件和本地数据不应直接提交到仓库
